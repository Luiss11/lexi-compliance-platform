## 📌 Resumen del Proyecto

**Lexi** es una plataforma web centralizada diseñada para pequeñas organizaciones que buscan gestionar, consultar y auditar el cumplimiento de políticas internas, contratos y regulaciones municipales. Incorpora un asistente de IA fundamentado (RAG) que responde consultas operativas citando de manera precisa las páginas y artículos de los documentos oficiales cargados.
