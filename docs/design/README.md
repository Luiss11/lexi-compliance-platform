## Tokens

| Token | Valor | Uso |
|---|---|---|
| paper | `#F5F4EF` | Fondo |
| ink | `#15171C` | Texto y barra lateral |
| muted | `#555B66` | Texto secundario |
| line | `#DEDBD2` | Bordes |
| lexi | `#0E5A55` | Acción principal, cumplimiento |
| warn | `#7A3D0B` / `#FBEEDD` | Alertas medias |
| danger | `#8A1F16` / `#F8E3DF` | Vencido, prioridad alta |
| info | `#1B4479` / `#E3ECF6` | Procesando, aviso |

Tipografía: IBM Plex Serif (títulos), IBM Plex Sans (texto), IBM Plex Mono (citas y hashes).
